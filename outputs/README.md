# Generated images

The executable saves generated PPM images here by default. These images are ignored
by Git because they can be regenerated from source. The foundation diagnostic is
not the completed CP1 dress or an algorithm demonstration.

Choose the final CP1 screenshots and save those in `docs/evidence/` so the evidence
is committed alongside the source that produced it. Open PPM images with a viewer
that supports Netpbm images, or convert a copy to PNG for presentation.
